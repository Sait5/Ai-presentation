# Презентации: AI, оформление и изображения

В редакторе картинку можно перетащить мышкой прямо на слайде; четыре угловые ручки меняют ширину и высоту. Изображение остаётся в пределах слайда, минимальный размер — 10% по каждой оси. Движение переводит картинку в свободное положение. Escape отменяет текущий жест; стрелки перемещают выбранную картинку или меняют размер выбранного угла (Shift увеличивает шаг). После изменения нажмите «Сохранить». В предпросмотре ручки скрыты, геометрия сохраняется в документе и используется при экспорте PPTX.

Текущий режим по умолчанию — Gemini. Используйте ключ проекта Google AI Studio Free Tier без подключённого Billing. Текст создаётся в пределах квоты выбранной модели; приложение не может определить тариф проекта по одному ключу. При исчерпании квоты запрос завершается понятной ошибкой без автоматического перехода на OpenAI. Генерация изображений в режиме Gemini заблокирована и на сервере, и в интерфейсе; загрузка своих файлов работает. Google может использовать данные бесплатного тарифа для улучшения продуктов. Условия: [тарифы Gemini](https://ai.google.dev/gemini-api/docs/pricing).

Откройте презентацию → «Оформление»: выберите одну из пяти тем, шрифт Arial/Georgia/Verdana, размер заголовка и текста, выравнивание, жирный или курсив. Можно включить отдельный стиль текста текущего слайда. Смена темы не перерисовывает уже созданные картинки: для нового художественного стиля загрузите замену (или сгенерируйте её в режиме OpenAI).

В панели «Создать презентацию с AI» задайте тему, аудиторию, цель, 3–15 слайдов и стиль изложения. Используются текущие тема, язык и настройки текста. Стиль иллюстраций допускает произвольное описание. Только в режиме OpenAI галочка «Создать картинки для всех слайдов» добавляет отдельный платный запрос для каждого слайда. Без галочки AI готовит текст и описания иллюстраций. Результат можно просмотреть, заменить им текущие слайды либо добавить в конец (общий лимит 40), затем сохранить. Ошибка изображения оставляет уже полученный черновик. До применения черновик хранится только в открытой странице; не закрывайте её во время работы.

В панели «Изображение слайда» загрузите PNG/JPEG/WebP; в режиме OpenAI также можно сгенерировать картинку по описанию и стилю. Результат сначала показывается отдельно, затем применяется кнопкой. Сейчас доступно одно изображение на слайд. Положения: слева, справа, сверху, снизу, фон и свободное. В свободном режиме доступны координаты и размер в процентах слайда; текст располагается поверх изображения. Также доступны обрезка/вписывание, непрозрачность и описание. Для фона добавляется затемнение и белый текст. Слайды, текст и картинки экспортируются в PPTX; координаты рассчитываются общим модулем, окончательные переносы зависят от шрифтов в PowerPoint. Размер текста автоматически уменьшается при недостатке места, непомещающийся материал отклоняется при экспорте.

## Подключение

В `server/.env` задайте `GEMINI_API_KEY`; не добавляйте его в клиент и не отправляйте в чат. `AI_PROVIDER=gemini` — значение по умолчанию, `GEMINI_MODEL=gemini-3.5-flash-lite`. Проект Google Cloud создаётся в AI Studio; загружать туда код Forma не требуется. Не подключайте Billing для бесплатного режима. После изменения перезапустите сервер. Без ключа возвращается понятная ошибка 503; загрузка собственных изображений работает.

Опциональный платный режим выбирается явно: `AI_PROVIDER=openai`, `OPENAI_API_KEY`, `OPENAI_MODEL` (gpt-6-astra), `OPENAI_IMAGE_MODEL` (gpt-image-2.5-sunburst). Описанные ниже запросы генерации картинок относятся только к этому режиму. Автоматического переключения провайдера нет.

Примените `npm --prefix server run db:deploy` для таблицы ImageAsset. Изображения принадлежат пользователю и хранятся в PostgreSQL BYTEA. В JSON документа содержится только ссылка. Копии и версии используют тот же asset, поэтому удаление документа не удаляет картинку. Лимит — 200 assets на аккаунт; удаление неиспользуемых assets и сборка мусора ещё не реализованы. Удаление пользователя каскадно удаляет его assets. Загружаемые файлы до 8 МиБ и 24 Мп декодируются через sharp, метаданные удаляются, размер уменьшается до 1600 px по длинной стороне. SVG, анимация и внешние URL не принимаются.

## API и проверки

- `GET /api/v1/ai/status` → enabled, provider, imageGeneration. enabled показывает наличие ключа, а не факт успешной проверки ключа провайдером.
- `POST /api/v1/ai/presentation` → редактируемый PresentationContent, без изменения документа в БД.
- `POST /api/v1/ai/image` → id/width/height сохранённого изображения.
- `POST /api/v1/images` → raw binary с Content-Type image/png, image/jpeg или image/webp.
- `GET /api/v1/images/:id` → PNG только для владельца; UI получает его с Bearer и создаёт временный object URL.

Все маршруты требуют сессию; POST также Origin и X-Requested-With. AI — 30 запросов/15 мин/IP и одна одновременная генерация на пользователя в процессе; загрузка — 60/15 мин/IP. Таймаут AI — 180 секунд, автоматических повторов нет. При перегрузке провайдера (503) возвращается AI_BUSY с предложением повторить позже. Для production нужны общая очередь, распределённые лимиты, бюджеты пользователей и фоновые задания. API-ошибки не публикуют ключ или необработанный ответ провайдера.

Проверка 16 сентября 2026: 23 unit/contract/export-теста и 2 интеграционных теста PostgreSQL, включая чужие изображения, сохранение/копирование, встроенные PNG в PPTX, отказ AI, незавершённый ответ и некорректные файлы. Шесть вариантов размещения отрисованы отдельным рендерером; справа и фоном просмотрены визуально. Сборка и lint проходят. Настоящие ответы OpenAI не проверены: локальный ключ отсутствует.

В браузере также проверены тёмная тема/Georgia, загрузка PNG, применение картинки слева, сохранение и перезагрузка, свободные координаты, сохранение версии 3 и скачивание PPTX (51322 байта). Кнопка остановки серии завершает текущий запрос без запуска следующего; уже выполняющийся запрос может быть оплачен. При уходе со страницы очередь новых изображений прекращается.

Источники интеграции: [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs), [генерация изображений](https://developers.openai.com/api/docs/guides/image-generation).

Проверка Gemini 16 сентября 2026: ключ принят запросом списка моделей (HTTP 200). `gemini-3.8-flash` и рекомендованная Google `gemini-3.6-flash` возвращали HTTP 503 из-за высокой нагрузки. `gemini-3.5-flash-lite` успешно создала три слайда и PPTX, поэтому выбрана моделью по умолчанию. В браузере проверена панель Gemini без платной генерации изображений.
